## 2. Обновить данные
```bash
cd engine/pob2 && git pull && cd ../..        # PoB: пулы, тиры, эссенции, деревья
python3 tools/update_poe2db.py                # превью весов и Alloy: смотреть diff (+/−, changed)
python3 tools/update_poe2db.py --apply        # заменить (старые → *.bak.json)
pkill -f "Python server.py"; python3 server.py &
```
PoB обычно выходит с поддержкой патча через несколько часов–дней после запуска. До этого крафт работает на старых
тирах — предупредить пользователя.

## 3. Поправить `gamedata.py`
Пройти файл сверху вниз: лимиты (`AFFIX_MAX`, `CRAFTED_MAX`, `FRACTURE_MIN_MODS…`, `ANCIENT_BONE_FLOOR`),
названия (`CUR`, `OMEN`, `ECHOES`, `LIGHT`, `LORD_OMEN`, `RUNE`, `CORRUPT_ESS`, `CATALYST`), пороги `FLOOR`,
`PAGE` (страницы poe2db), `TRADE_CAT`, `NINJA_TYPES` (новые разделы poe.ninja).

## 4. Прогнать контрольные крафты
```bash
python3 tests/regress.py --league "<новая лига>"
```
- `FAIL нет цены на poe.ninja: …` — переименовали/убрали валюту → п.3.
- `FAIL error: …` — сломался разбор данных PoB или правила → смотреть трассу в ответе задания.
- `WARN цена ×…` — нормально, если изменились цены или веса; ненормально, если ×10.
После проверки — `python3 tests/regress.py --save` (новый эталон под новую лигу).

## 5. Проверить вручную (5 минут)
- Вкладка «Крафт»: вставить предмет из игры (Ctrl+C) → «Рассчитать» → гайд, пошаговый режим, «Найти такие же на трейде».
- Загрузить билд → «Поиск замены» по одному слоту (трейд + PoB).
- Иконки валюты на шагах (poe.ninja), фон, карточка базы.
