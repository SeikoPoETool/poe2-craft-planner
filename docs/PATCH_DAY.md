# Что делать в день патча

Цель — за час понять, что сломалось, и вернуть приложение в рабочее состояние.

## 1. Прочитать патчноут
Отметить всё, что касается приложения:
- валюта, омены, кости, эссенции: переименования, новые, удалённые, пороги уровня у Greater/Perfect;
- лимиты: число аффиксов, крафт-модов, десекрейт-модов; правила Fracturing Orb, Crystallisation, Putrefaction;
- новые механики крафта, классы предметов, базы, тиры и веса модов;
- трейд: новые категории и статы;
- новая лига — `gamedata.DEFAULT_LEAGUE`.

## 2. Обновить данные
```bash
cd engine/pob2 && git pull && cd ../..     # PoB: пулы модов, тиры, эссенции
python3 tools/update_poe2db.py             # превью весов и Alloy (смотреть diff)
python3 tools/update_poe2db.py --apply     # применить (старые файлы → *.bak.json)
```
Перезапустить сервер. PoB с поддержкой патча обычно выходит через несколько часов или дней — до этого крафт
считается по старым тирам.

## 3. Поправить `gamedata.py`
Пройти файл сверху вниз: лимиты (`AFFIX_MAX`, `CRAFTED_MAX`, `FRACTURE_MIN_MODS…`, `ANCIENT_BONE_FLOOR`),
названия (`CUR`, `OMEN`, `ECHOES`, `LIGHT`, `LORD_OMEN`, `RUNE`, `CORRUPT_ESS`, `CATALYST`), пороги `FLOOR`,
страницы poe2db `PAGE`, `TRADE_CAT`, разделы poe.ninja `NINJA_TYPES`.

## 4. Прогнать контрольные крафты
```bash
python3 tests/regress.py --league "<новая лига>"
```
- `FAIL нет цены на poe.ninja` — валюту переименовали или убрали → п. 3.
- `FAIL error` — сломался разбор данных PoB или правила.
- `WARN цена ×…` — нормально при изменении цен и весов, подозрительно при ×10.

Когда всё в порядке — `python3 tests/regress.py --save` (новый эталон).

## 5. Проверить руками
- «Крафт»: вставить предмет из игры → «Рассчитать» → гайд, пошаговый режим, «Найти такие же на трейде».
- Загрузить билд → «Поиск замены» по одному слоту.

## 6. Новые механики
Добавлять по официальному патчноуту: см. «Куда добавлять новое» в `docs/CRAFT_PLANNER.md`. Каждой — свой этап
перебора и контрольный крафт в `tests/cases/`.
