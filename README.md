# poe2-craft-planner — планировщик крафта и подбор предметов для PoE2

Локальное приложение для Path of Exile 2. Все числа считает настоящий Path of Building (PoE2) в фоне,
а приложение подбирает вещи на трейде под ваш билд, даёт настроить конфиг и планирует крафт.

English version: [README.en.md](README.en.md).

## Скачать и запустить (без программирования)
**Windows:** скачайте [poe2-craft-planner-setup.exe](https://github.com/SeikoPoETool/poe2-craft-planner/releases/latest/download/poe2-craft-planner-setup.exe)
и запустите. Установка без прав администратора, ярлыки «PoE2 Craft Planner» в меню «Пуск» и на рабочем столе; всё
нужное, включая Python, внутри. Если появится «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в
любом случае» (приложение не подписано). Удаление — «Параметры → Приложения». Обновление — запустить новый установщик
поверх старого, сохранённые ссылки на крафты останутся.

**macOS и Linux** (и Windows без установки):
1. Откройте [последний релиз](https://github.com/SeikoPoETool/poe2-craft-planner/releases/latest) и скачайте архив для своей системы:
   `poe2-craft-planner-macos.zip` (Mac на Apple Silicon: M1 и новее), `poe2-craft-planner-linux.zip` или
   `poe2-craft-planner-windows.zip`.
2. Распакуйте его куда угодно (например, в «Документы»).
3. Запустите:
   - **Windows (архив):** двойной щелчок по `start.bat`.
   - **macOS:** двойной щелчок по `start.command`. В первый раз macOS скажет, что не может проверить разработчика
     (приложение не подписано Apple): «Системные настройки → Конфиденциальность и безопасность» → «Всё равно открыть»
     рядом с start.command, подтвердить. Если нет Python, macOS предложит его установить — потом запустите снова.
   - **Linux:** `./start.command` в терминале (нужен `python3`).
4. Приложение откроется в браузере: http://127.0.0.1:8765. Чёрное окно не закрывайте, пока пользуетесь; закрыли —
   приложение остановилось.

Обновление: скачайте новый архив и перенесите в него папку `cache` из старого (там ваши сохранённые ссылки на крафты).

## Установка из исходников (для разработчиков)
Нужны macOS или Linux, Python 3.9+, git и компилятор C (macOS: `xcode-select --install`;
Debian/Ubuntu: `sudo apt install build-essential git`). На Windows используйте готовый архив (см. выше).
```bash
git clone https://github.com/SeikoPoETool/poe2-craft-planner.git
cd poe2-craft-planner
./install.sh          # один раз: Path of Building (submodule), сборка LuaJIT и lua-utf8
python3 server.py     # затем http://127.0.0.1:8765  (на macOS — двойной клик по start.command)
```

## Вкладки
- **Предметы** — кукла как в игре.
- **Гемы** — группы гемов билда как они есть; клик по скиллу делает его основным.
- **Конфиг** — вкладка Configuration из PoB. При загрузке билда неработающие опции снимаются, а то, что билд делает
  по расчёту PoB (шок, поджог, заморозка, триггер, крит), включается. «Сверх PoB»: энергия мета-гемов.
  Ваши правки конфига запоминаются в браузере для этого билда.
- **Поиск замены** — веса модов из PoB → взвешенный поиск на трейде → каждый кандидат пересчитывается в PoB.
  «Что улучшать первым» проверяет все слоты; по его результатам можно составить план покупок под бюджет.
- **Джевелы** — редкие, Time-Lost и уникальные джевелы для любых сокетов дерева.
- **Крафт** — вставьте предмет (цель или ваш текущий) или выберите базу и нужные моды; приложение подбирает
  самую дешёвую по ожиданию последовательность валюты и показывает шаги, шансы и закупку. «С моего предмета» открывает
  редактор «Мой предмет сейчас»: редкость, число сокетов и моды с тиром и видом (обычный, фрактур,
  десекрейт, крафт), плюс «ненужный префикс/суффикс». Вставленный текст заполняет его же, а без текста предмет собирается
  руками от выбранной базы. Свободный сокет — руна без Artificer's Orb. Цена вашего предмета (поле «Цена моего предмета (базы)») входит в итог отдельной строкой. Если выгоднее бросить предмет (промах фрактура) и начать заново, берётся ещё один
  такой же предмет по той же цене.

«Экспорт в PoB» (вверху) отдаёт код билда с изменённым здесь конфигом — его можно вставить в PoB через Import.
«Примерить» в результатах поиска показывает сравнение с надетым предметом; в билд ничего не надевается.

## Как считается поиск
- Веса: каждый мод ставится на пустой предмет слота и пересчитывается в PoB (как TradeQueryGenerator в PoB).
- Трейд: порог суммы весов подбирается так, чтобы совпадений было меньше 10000 (иначе трейд сортирует не всё);
  берутся 10 сильнейших и 10 самых дешёвых. Второй проход подгоняет веса под оценки PoB и ищет ещё раз.
- Продавцы по умолчанию — «мгновенный выкуп и лично (онлайн)», как Instant Buyout and In Person на трейде.
- «Цена доп. 1%» — сколько divine стоит каждый процент сверх лучшего более дешёвого варианта.
- «Броня / Уклонение / ES предмета» (в «Других метриках») — мин/макс как в Equipment Filters трейда, только для брони; макс 0 убирает базы с этой защитой (например, гибриды EV/ES).
- **Косвенные моды** (галочка, по умолчанию включена). Сюда попадают моды, которые PoB не переводит в DPS основного скилла,
  но которые его усиливают, если в билде есть механика:
  - скорость снарядов, доп. снаряды, пробивание, цепи и площадь (зачистка; в PoE2 скорость снарядов не прибавляет дальности);
  - дальность переката с Cast on Dodge (энергия за метр, база 3.7 м);
  - Archon (25% more на 10 с, затем 20 с перезарядки);
  - Elemental Infusion, Invocation, Glory, Remnants, заряды.

  Каждый мод получает оценку «≈ N% DPS» по правилу с коэффициентом. Правило срабатывает, только если PoB сам даёт строке 0 DPS.
  Оценка входит в прирост с весом метрики DPS и помечается «низк. увер.». Пометка «средн. увер.» значит, что значение посчитано
  в PoB с допущением: например, условие «если собрали Infusion» считается выполненным 75% времени. Правила лежат в
  `engine/worker.lua` (HEUR_RULES).

## Как считается крафт
- Пул модов, тиры и эссенции берутся из PoB, моды лордов (Kurgal, Amanamu, Ulaman) — из пула десекрейта PoB,
  какой мод даёт каждый Alloy на каком классе предмета — с poe2db (`engine/alloys.json`), цены — с poe.ninja.
- Весов выпадения модов в файлах игры нет. Берутся веса poe2db для этого класса и типа базы (`engine/mod_weights.json`):
  обычно 1000, на гибридных базах меньше, у топ-тиров ниже. Модам без опубликованного веса (Marksman от Kolr's Hunt,
  моды лордов) ставится средний опубликованный вес тиров того же ранга (1-й, 2-й… сверху) на этой базе. Поэтому шансы — оценка.
- В тексте предмета из обычного Ctrl+C крафт-моды не помечены. Строку, которой нет среди обычных модов базы
  (или второй мод той же группы), приложение относит к Alloy или эссенции; гибрид может забрать и строку,
  похожую на обычный мод (Transcendent Alloy: Cast Speed + extra Cold). Так, чтобы вышло не больше 3+3 модов.
- «Рассчитать» сам разбирает вставленный текст, если он новый. «Grants Skill: …» — навык базы, не мод. Качество каталистов
  («Quality (Caster Modifiers): +40%») учитывается при узнавании модов: caster-моды показаны ×1.4 (+3 к спеллам → +4).
  Лимиты аффиксов базы берутся из её импликитов (Absent Amulet: −1 префикс, −1 суффикс → 2 + 2); мод, который бывает и
  префиксом, и суффиксом (Rarity на амулетах), раскладывается под эти лимиты.
- Моды Otherworldly (Altered Collarbone, бижутерия): узнаются как десекрейт-моды; как цель — Altered Collarbone, одна из
  3 опций считается Otherworldly (как с оменами лордов; это допущение — точной механики в данных нет).
- **Качество до 40%** («По желанию», бижутерия): если последний крафт-мод заменяет мусорный префикс, перед ним можно
  поставить Essence of the Breach (+20% к максимуму качества), довести качество каталистом до 40% (каталист выбирается
  по тегам нужных модов: caster → Sibilant), а потом этот крафт-мод заменит Breach-мод — качество останется.
- Лучшая стратегия прогоняется от 8 000 до 20 000 раз — пока 95% интервал средней не станет уже ±2%;
  интервал показан рядом с ценой. Новый расчёт крафта отменяет незаконченный предыдущий.
- Способ получения каждого мода выбирается сам: обычный слэм, десекрейт (3 варианта, Abyssal Echoes перекидывает все 3),
  эссенция; какой мод фрактурить первым — тоже. Перебираются разные распределения, лучшие считаются полностью.
- Скорость: быстрый отбор и каждый этап перебора идут в два прохода — сначала часть прогонов для всех вариантов, остальное
  только тем, кто не хуже лучшего в 2 (отбор) или 1.8 (этапы от 8 вариантов) раза; этапы с несколькими вариантами считаются целиком. Полностью прорабатываются лидер отбора и лучший
  вариант каждого другого разбиения пула. Если Putrefaction дешевле любого обычного варианта больше чем в 2.5 раза,
  обычные остаются грубой оценкой в «Других стратегиях».
- Каждая стратегия разыгрывается тысячи раз (Монте-Карло): как получить первый мод (Transmute/Augment на белых базах
  или Chaos на редком), фрактур (4 мода или 3 мода + нераскрытая кость), какой Exalted и омены, чем убирать мусор
  (Annul, Annul с оменом стороны, Chaos + Whittling), когда ставить крафт-моды (эссенции, Alloy с оменом Crystallisation;
  в том числе «Exalted на сторону без нужных модов, промах заменить крафт-модом»),
  какая кость и нужны ли Abyssal Echoes, чем снимать неудачный десекрейт (Annul + Omen of Light, обычный Annul или
  Essence of the Abyss + Crystallisation: на месте мода остаётся Mark of the Abyssal Lord, следующая кость превращает его
  в новый десекрейт; рядом с другим крафт-модом нужна Astrid's Creativity). Выбирается самая дешёвая по средней стоимости.
- Правила 0.5: 3 префикса + 3 суффикса (Serle's Triumph: +1 суффикс), один крафт-мод (Astrid's Creativity: +1),
  один десекрейт-мод; Kolr's Hunt открывает моды Marksman на перчатках; руны выбирает сам расчёт: Serle's — если суффиксов больше трёх,
  Astrid's — если стратегия ставит два крафт-мода; руны, уже вставленные в ваш текущий предмет, не покупаются заново. Crystallisation снимает мод только своего типа (префикс или суффикс), и применить его можно, только если такой мод есть: Alloy всегда что-то заменяет. Если заменять нечего, сначала обычным Exalted добавляется мод под замену (если другие аффиксы заполнены, он гарантированно ляжет куда нужно). Если все снимаемые моды одного типа, омен не нужен.
  Fracturing Orb не выбирает нераскрытый десекрейт-мод. Омены лордов работают только на оружии и бижутерии.
- Крафт-моды (Alloy, эссенции) ставятся в таком порядке, чтобы омен Crystallisation снимал пустое место или мусор, а не
  уже поставленный крафт-мод: на палочке с +4 (суффикс) сначала суффиксный Alloy + Sinistral, потом префиксный. Если
  снять можно только нужный мод, снимается тот, что дешевле вернуть. Или (вариант стратегии, расчёт сам сравнивает на полных крафтах) сначала
  Chaos + Omen of Whittling снимает мусор самого низкого уровня. Пример: эссенция даёт суффикс, а суффиксы заполнены —
  добавить префикс и заменить его нельзя, место нужно именно под суффикс.
- Чистка: обычный Annul или Annul с оменом стороны — что дешевле с учётом риска снять нужный мод (риск = шанс × во что
  обойдётся вернуть этот мод). Поэтому иногда дешевле рискнуть дешёвым крафт-модом и поставить его заново, чем платить за омен.
- Фрактур: если Fracturing Orb закрепил не запланированный, а другой нужный мод не легче его (например Cold вместо Fire
  резиста), предмет годится — запланированный мод добавляется дальше слэмом. Закреплённый мусор или заметно более лёгкий мод —
  новая база (слэмить трудный мод без защиты дороже).
- **Отменить** останавливает расчёт; **Ссылка на крафт** даёт короткую ссылку (`#craft=код`) на базу, моды, тиры и пул —
  открывается и без загруженного билда (хранится в `cache/craft_links.json`). С начального экрана «Крафт» открывается без билда.
- **Цель задаётся как фильтры статов на трейде**: блок «И» (все моды обязательны) и сколько угодно групп «Count» (нужно
  любых N из группы; N = 0 — группа не нужна, её моды в расчёт не идут); у каждого мода свой столбец тира («T1», «≥T2»…); чтобы перенести мод в другую группу, уберите его и добавьте туда. Моды выбираются из окна в стиле трейда (ввод фильтрует,
  стрелки + Enter). Псевдо-моды, как на трейде: «+#% total Elemental Resistance», «+#% total Resistance», «+#% total to
  Fire/Cold/Lightning/Chaos Resistance» с минимумом и «# Empty Prefix/Suffix Modifiers». Сумму расчёт превращает в «любые
  k резистов не ниже X/k» с тем k, который проще собрать (≥60 → 2 резиста от 31%, ≥90 → 3 от 31%); пустые аффиксы — свободные
  места, которые крафт не занимает. Сверка с трейдом ищет по самим псевдо-статам. Псевдо-мод можно положить и в группу Count — как один вариант её заполнить: в расчёте
  это «один мод, который сам набирает значение» (сумма элементальных резистов ≥ 40 → любой резист от 41%); сумму, которую
  одним модом не набрать, внутри Count расчёт не моделирует и говорит об этом. Пустые аффиксы — только в «И».
- Сверка с трейдом — по кнопке «Найти такие же на трейде». Если расчёт выбрал Omen of Putrefaction, кнопка
  «Крафт без Putrefaction» пересчитывает обычный путь (предмет не будет corrupted).
- **Пул модов** (одна группа, прежний вид): подходит любой из отмеченных модов, сколько нужно — задаётся под таблицей.
  Расчёт сам решает, какие из пула ловить: кроме общей стратегии он проверяет самый лёгкий конкретный набор для каждого
  разбиения пула на префиксы и суффиксы (2 + 2, 1 + 3…; их можно фрактурить и десекрейтить), поэтому пул не выходит дороже
  хорошего конкретного набора.
  В пул можно класть только моды, которые выпадают от Exalted. Даже когда расчёт выбрал конкретный набор из пула,
  любой другой мод пула на той же стороне засчитывается вместо него (Cold вместо Fire) — при слэмах и при раскрытии кости.
- **Первый шаг** (синий предмет на новых базах, потом фрактур или нет): расчёт сам выбирает, что принимать —
  только запланированный мод; другие нужные моды под слэм, которые выпадают не чаще него; ещё и мод, запланированный под
  десекрейт (тогда они меняются ролями: зафрактурился flat ES вместо % ES — % ES получаем десекрейтом); или любой мод пула
  (flat ES вместо Fire резиста). Список принятых модов написан в описании стратегии. Одинаковый вес ещё не значит
  «равноценны»: если у мода больше младших тиров ниже нужного (у % ES: 46/54/60 под 65), они чаще занимают его место при
  слэмах и десекрейте, поэтому его выгоднее закрепить первым.
- Подсказка про Augment говорит конкретно: «только если Transmute дал суффикс — Augment добавит префикс». В пошаговом
  режиме цикл и вопрос «что выпало» — один шаг (без отдельного «Получилось»); затем приложение спросит второй
  аффикс синего предмета (вдруг он тоже нужен; если цель уже называет его однозначно — не спросит). И оставлять ли синий предмет, на котором сразу два нужных мода (префикс + суффикс),
  хотя запланированного нет. Эти правила сравниваются на полном крафте, а не только на первом шаге: «брать что угодно»
  дешевле на первом шаге, но оставляет больше работы потом.
- Как получить первый мод (обычный / Greater / Perfect Transmute, одна база + Annul, Chaos) сравнивается по точному шансу
  каждого фрактура, а не по тому, сколько Fracturing Orb ушло в конкретных прогонах — иначе разница в доли div тонет в шуме.
- **Omen of Putrefaction**: кость с этим оменом заменяет все моды редкой базы 6 нераскрытыми (считается 3 префикса + 3 суффикса)
  и делает предмет corrupted; каждый мод раскрывается в Well of Souls как выбор 1 из 3 (Abyssal Echoes перекидывает варианты),
  варианты — из пула десекрейта (обычные моды базы + моды лордов) с обычными весами. Не собралось — новая база;
  как только набор уже не собрать, Echoes на оставшиеся моды не тратятся. Редкой база становится через Orb of Alchemy
  или Transmute + Augment + Regal — что дешевле. Echoes сравнивается в трёх вариантах: на каждом промахе, никогда
  (сразу новая база) и только когда без этого мода набор уже не собрать. Расчёт сравнивает это с обычным крафтом
  (Preserved / Ancient кость, с Echoes и без) и показывает кнопку, чтобы посчитать второй вариант. Только если все нужные
  моды выпадают при раскрытии (без эссенций, Alloy, Kolr's Hunt). Механика взята из описаний, а не из файлов игры: проверьте
  на одной базе, что выходит 3 + 3 и что варианты такие же, как при обычном десекрейте.
- Все сферы, омены, кости и эссенции — по текущему курсу выбранной лиги (poe.ninja); цену белой базы вписываете вы.
  Дорогие эссенции и Alloy (от 1 div) ставятся, только когда все остальные нужные моды уже на предмете.
- **Новая база вместо чистки**: расчёт проверяет, не дешевле ли при мусоре взять новую базу, пока нужных модов мало;
  в пошаговом режиме это выбор («Новая база» или «Продолжить: убрать мусор»).
- **Эссенции везде, где они дешевле:** при переходе синего в редкий — магическая эссенция на ещё не собранный мод вместо
  Regal (если дешевле 1 div); на редком — Perfect/редкая эссенция с Crystallisation вместо слэмов, если ловить мод Exalted
  (с промахами и чисткой) выходит дороже (расчёт сравнивает это и без этого на полных крафтах). Regal — обычный, Greater или
  Perfect: цена против шанса сразу получить нужный мод.
- **Финиш костью** («По желанию», в цену крафта не входит): если все нужные моды на месте, есть свободный аффикс и ещё нет
  десекрейт-мода — Preserved кость + Abyssal Echoes: выбор самого полезного мода из 3 (с Echoes ещё из 3) вместо Exalted
  вслепую, чтобы предмет стоил дороже.
- **Кость вместо Exalted**: если ни один нужный мод не делается десекрейтом (или эта роль уже закрыта эссенцией),
  единственный десекрейт-слот предмета идёт под самый редкий недостающий обычный мод (в том числе из группы Count):
  кость + Necromancy-омен на нужную сторону, выбор 1 из 3 (с Echoes ещё 3). Промах — дальше Exalted, или
  Annul + Omen of Light и кость снова; расчёт сравнивает это с Exalted и выбирает дешевле.
- **Эссенция в пошаговом режиме — отдельный шаг** с кнопкой «Сделал»: что применить и какой мод она гарантирует.
- **Сверка с трейдом в группе Count**: гибридный мод (% ES / + мана) учитывается одной строкой — той, которой нет у
  других модов группы, а одинаковый стат двух модов — одним фильтром (иначе один мод ES засчитывался за несколько).
- Фон страницы — картинка `static/bg.webp`, если она есть (в репозитории её нет: это арт GGG), размыта и затемнена.
- Крафт, который не уложился в лимит действий, входит в среднюю с тем, что уже потратил, а не выбрасывается.
- Kolr's Hunt ставится в каждую базу, только если фрактурится мод Marksman (промах фрактура = новая база);
  иначе — один раз после фрактура. Шаги до фрактура в гайде показаны на одну попытку и с числом попыток.
- Первый мод на синем: новая белая база на каждую попытку или одна база с Annul + Augment — выбирается дешевле.
- **Пошагово** (переключатель над шагами): приложение ведёт по выбранной стратегии, а на каждом случайном исходе спрашивает,
  что получилось в игре («Что добавилось?», «Какой мод снялся?», «Какой мод зафрактурился?», «Есть нужный в 3 вариантах?»).
  Следующий шаг считается от ответа: если снялся нужный мод, приложение говорит, как его вернуть. «Назад» меняет ответ.
  Справа — окно предмета как в игре (префиксы/суффиксы, фрактур, крафт, десекрейт; только что появившийся мод подсвечивается).
  Валюта каждого действия — отдельными значками (иконки с poe.ninja), циклы помечены «Повторять до результата».
  Если Fracturing Orb закрепил не тот мод, приложение прямо говорит, что предмет не годится и выгоднее новая база.
  Пошаговый режим живёт, пока не перезапущен сервер.
- **Сверка с трейдом** (кнопка в результатах): вывод крупной плашкой (во сколько раз крафт выгоднее или дороже, прибыль при продаже по цене самого дешёвого похожего, доля крафтов в плюс); 5 самых дешёвых похожих — по строке на предмет, клик ведёт на трейд (лоты этого продавца с этой базой), при наведении — окно предмета как в игре (картинка, уровень, моды). взвешенный поиск онлайн, как в подборе улучшений: каждый нужный мод на нижней
  границе своего тира даёт 1, предмет должен набрать ≥ 90% суммы, и при этом каждый мод сам не ниже 90% нижней границы
  тира (целые значения — с округлением вверх: +5 к уровню спеллов так и остаётся +5, 188 маны → от 170). Сильный мод не
  перекрывает слабый. Фильтр «explicit» на трейде ловит и фрактур, и десекрейт, и крафт-версию мода, поэтому каждый мод — одним фильтром.
  Одна и та же характеристика из двух нужных модов (+4 к уровню спеллов и +1 из Celestial Alloy) ищется одним фильтром
  на сумму (+5), иначе +3 засчитывался бы дважды. Ищутся продавцы с мгновенным выкупом и онлайн. Показана средняя прибыль при продаже по цене самого дешёвого похожего
  и доля крафтов, которые выходят в плюс. Если на той же базе меньше 5 объявлений, поиск расширяется на все базы этого типа. Без POESESSID большой взвешенный
  запрос трейд может не принять — тогда ищется без весов, каждый мод не ниже 90% тира.
  Найденное **проверяется по настоящим модам предмета** (трейд отдаёт имя, тир и уровень каждого мода; гибрид — один
  мод на двух строках): «И» и каждая группа Count должны собраться с тиром не ниже нужного. Самые дешёвые проверяются
  по 10, пока не найдётся 5 подходящих (до 60); над таблицей видно, сколько отсеяно.
- Логика в `craft.py`, правила и названия игры — в `gamedata.py`.

## Данные и безопасность
- POESESSID хранится только в памяти сервера; галочка «помнить» сохраняет его в этом браузере.
- Сервер слушает только 127.0.0.1 и принимает запросы только со своей страницы.
- Пока идёт поиск на трейде, билд менять нельзя (иначе часть предметов посчиталась бы против другого билда).
- Обновить PoB: `cd engine/pob2 && git pull`.
- Проект не связан с Grinding Gear Games. Path of Exile — товарный знак Grinding Gear Games.

## Для разработчика
- `docs/` — архитектура, планировщик крафта, трейд и источники данных, установка на другой компьютер, план на день
  патча.
- `python3 tests/regress.py` — контрольные крафты против эталона (сервер должен работать).
- `python3 tools/update_poe2db.py` — пересобрать веса модов и Alloy с poe2db (после патча).
