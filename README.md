# poe2-craft-planner

Помощник для Path of Exile 2: считает, как дешевле всего скрафтить нужный предмет, и подбирает на трейде вещи
под ваш билд. Работает у вас на компьютере, а все цифры по билду считает настоящий
[Path of Building](https://github.com/PathOfBuildingCommunity/PathOfBuilding-PoE2).

English version: [README.en.md](README.en.md)

## Что умеет

- **Крафт.** Вы говорите, какой предмет хотите, — приложение перебирает способы (Exalted, Chaos, эссенции, Alloy,
  кости, фрактур, омены…), находит самый дешёвый в среднем по текущим ценам poe.ninja и ведёт по шагам.
- **Подбор вещей.** Загружаете билд — приложение ищет на трейде предметы, которые сильнее всего поднимут DPS или
  защиту, и проверяет каждый в PoB.
- **Джевелы, конфиг PoB, экспорт билда** обратно в Path of Building.

## Установка

**Windows.** Скачайте [poe2-craft-planner-setup.exe](https://github.com/SeikoPoETool/poe2-craft-planner/releases/latest/download/poe2-craft-planner-setup.exe)
и запустите. Права администратора не нужны, Python ставить не надо — всё внутри. Появится ярлык «PoE2 Craft Planner».

**macOS (M1 и новее) и Linux.** Скачайте архив для своей системы со
[страницы релиза](https://github.com/SeikoPoETool/poe2-craft-planner/releases/latest), распакуйте и запустите
`start.command` (на Linux — `./start.command` в терминале, нужен `python3`).

Приложение откроется в браузере. Чёрное окно не закрывайте, пока пользуетесь: закрыли — приложение выключилось.

> Приложение не подписано, поэтому при первом запуске система предупредит.
> **Windows:** «Подробнее» → «Выполнить в любом случае».
> **macOS:** «Системные настройки → Конфиденциальность и безопасность» → «Всё равно открыть».

**Обновление:** Windows — запустите новый установщик поверх старого. macOS/Linux — скачайте новый архив и
перенесите в него папку `cache` из старого (там ваши ссылки на крафты).

## Крафт

1. Откройте вкладку «Крафт». Вставьте предмет из игры (Ctrl+C) или выберите базу.
2. Нажмите «Разобрать» и отметьте моды, которые нужны, и минимальный тир.
   Группа «Count» — это «любые N из списка», как на трейде.
3. Впишите цену белой базы и нажмите «Рассчитать».
4. Получите гайд по шагам и среднюю стоимость в divine.
   - **Пошагово** — вы крафтите в игре, приложение спрашивает, что выпало, и говорит, что делать дальше.
   - **Найти такие же на трейде** — сравнить стоимость крафта с ценой готового предмета.
   - **Ссылка на крафт** — короткая ссылка, по которой можно вернуться к этой цели.

Если крафтите со своего предмета, выберите «С моего предмета» и укажите его цену — расчёт продолжит с него.

Стоимость — средняя по тысячам виртуальных крафтов: конкретный крафт может выйти дешевле или дороже. Шансы
модов — оценка по весам poe2db (в файлах игры их нет).

## Подбор вещей

1. Вставьте ссылку pobb.in или код из Path of Building и нажмите «Загрузить».
2. Вкладка «Поиск замены»: выберите слот, при желании — обязательные моды и максимальную цену,
   вставьте POESESSID и нажмите «Найти».
   Можно и с куклы: кликните по предмету, отметьте моды, которые должны остаться, — «Найти с выбранными модами».
3. В таблице — прирост в процентах и цена. «Примерить» сравнивает предмет с надетым.

«Что улучшать первым» проверяет все слоты сразу и показывает, где самый выгодный апгрейд (5–15 минут —
у трейда лимиты на запросы).

### POESESSID

Без него трейд не принимает «умный» взвешенный поиск. Где взять: войдите на pathofexile.com, нажмите F12 →
Application → Cookies → pathofexile.com → строка POESESSID.

Ключ уходит только на pathofexile.com. Сохраняется он лишь в вашем браузере и только если отметить
«помнить на этом компьютере». Если поиск пишет, что запрос слишком сложный, — ключ устарел, возьмите новый.

## Если что-то не так

- **Расчёт крафта идёт долго.** Сложные цели считаются до полутора минут — это нормально.
- **«Сервер перезапускался».** Страница сама загрузит билд заново и повторит действие.
- **Порт занят.** Запустите с другим портом: `PORT=8800 python3 server.py`.
- **Нашли ошибку** — создайте issue на GitHub и приложите ссылку на крафт (`#craft=…`).

## Для разработчиков

Нужны Python 3.9+, git и компилятор C (macOS: `xcode-select --install`; Ubuntu: `sudo apt install build-essential git`).

```bash
git clone https://github.com/SeikoPoETool/poe2-craft-planner.git
cd poe2-craft-planner
./install.sh          # один раз: Path of Building и сборка LuaJIT
python3 server.py     # http://127.0.0.1:8765
```

- `python3 tests/regress.py` — контрольные крафты против эталона (сервер должен работать).
- `python3 tools/update_poe2db.py` — обновить веса модов после патча.
- Как всё устроено — в [`docs/`](docs): архитектура, планировщик крафта, трейд и источники данных, установка,
  что делать в день патча.
- Каждый push в `main` собирает установщик и архивы для всех систем и публикует их в релиз.
